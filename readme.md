# 🛡️ Writeups

Bienvenido a mi repositorio de **writeups** sobre diferentes plataformas de ciberseguridad, pentesting y resolución de laboratorios.

En este repositorio recopilo el proceso de resolución de máquinas y retos, documentando la metodología seguida, las herramientas utilizadas y los aprendizajes obtenidos durante cada ejercicio.

> **Nota:** Todos los writeups respetan las políticas de divulgación de las plataformas correspondientes y solo se publican cuando está permitido.

## 🎯 Objetivos

- Documentar mi aprendizaje en ciberseguridad.
- Compartir metodologías de enumeración, explotación y post-explotación.
- Mantener una base de conocimiento personal.
- Servir como referencia para futuras resoluciones.

## 🛠️ Contenido de los writeups

Cada writeup puede incluir:

- Reconocimiento y enumeración.
- Identificación de vulnerabilidades.
- Explotación.
- Escalada de privilegios.
- Persistencia (cuando aplique).

## ⚠️ Disclaimer

Todo el contenido de este repositorio tiene fines exclusivamente educativos. No se promueve el uso de estas técnicas sobre sistemas para los que no se tenga autorización expresa.
